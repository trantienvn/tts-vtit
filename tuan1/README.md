# Tuần 1: Cắt Giao Diện HTML/CSS (VSS Chat Platform)

Thực hành cắt giao diện pixel-perfect theo thiết kế Figma cho ứng dụng **VSS Chat Platform**.

---

## 🎯 Mục Tiêu & Kết Quả

- **Thiết kế Responsive**: Tương thích tốt trên màn hình máy tính và thiết bị di động.
- **Giao diện hiện đại**: Tone màu Lavender sang trọng, hiệu ứng Blob mềm mại ở phần background bên phải.
- **Tích hợp Vector Icon**: Logo VSS Robot sắc nét dạng inline SVG.
- **Form Đăng nhập & Đăng ký**: Typography hài hòa, các thẻ `<input>`, `<button>` có hiệu ứng hover mượt mà.

---

## 📂 Cấu Trúc Thư Mục

```text
tuan1/
├── index.html    # Trang HTML Đăng nhập & Đăng ký
└── style.css     # CSS Styling & Layout Flexbox/Grid
```

---

## 🚀 Hướng Dẫn Khởi Chạy

1. Mở trực tiếp file `index.html` bằng bất kỳ trình duyệt web nào (Chrome, Edge, Firefox, Safari).
2. Hoặc mở thư mục trong VS Code và sử dụng extension **Live Server** để xem giao diện.
